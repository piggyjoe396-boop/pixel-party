# 超级马里奥风格：像素平台冒险

纯 HTML / CSS / JavaScript，手机和电脑浏览器都能玩，无上传入口。正式资源全部在 config.js 填写 src；留空则使用 pixel-art.js 中的内置像素占位图。

## 运行与文件

打开 index.html，或将整目录放到静态网站。加载顺序：config.js → pixel-art.js → puer-backgrounds.js → sound.js → game.js。style.css 负责手机竖屏、像素界面和弹窗。

## 玩法

电脑：← → / A D 移动，空格 / ↑ / W 跳跃，P 暂停。
手机：按住左、右按钮移动，点击 A 跳跃，也可点击游戏画面跳跃。游戏操作区禁用长按选字与系统菜单（含 iOS Safari）；松手、触控取消或失去指针捕获都会停止移动。图文页仍可正常滚动。

角色不会自动跑。关卡含实体水管、砖块、问号块、坑洞、金币和巡逻怪物。水管需要跳越，问号块从下方顶出可见金币，金币向上弹出并旋转约 0.65 秒后计入数量，显示 +100 分，已使用砖块不重复出币，怪物从上方踩掉。落坑返回最近存档点，保留已收集金币和装扮。蘑菇放在第二层砖块平台，需踩矮台阶再跳上去实际接触拾取，两套装扮随机解锁且不重复，立即展示装扮卡。时间只统计有效游玩，不含卡片和暂停。

每关按正常操作约 30 秒的路线设计：duration 默认 30，实际路线长 duration × 150 个世界单位。移动速度 150 单位/秒，两颗蘑菇位于路线的 1/3 和 2/3，每套装扮体验约 10 秒，测试路线约 30.3 秒抵达；不设强制倒计时，停留、回头或落坑会延长实际通关时间。

完整流程：像素地图（基础主角站在当前关）→ 角色介绍卡 → 手动平台跳跃 → 两次变装 → 终点售票站（三位伙伴在柜台后欢呼）→ 本关金币交付动画 → 目的地机票弹窗 → 点击确认 → 可上下滑动的图文页 → 点击前往下一关地图 → 基础主角沿路线跑到下一关 → 点击进入。

## 集中配置

| 配置键 | 用途 |
| --- | --- |
| duration | 路线目标时长，默认 30；不是倒计时 |
| hero.src | 默认主角，游戏和地图共用 |
| portrait.src | 每关开场卡角色照片，留空使用 hero |
| monster.src / mushroom.src / coin.src | 怪物、蘑菇、金币 |
| station.src | 售票站前景柜台 |
| friends[0..2].src | 三位独立伙伴，三关共用 |
| mapBackground.src | 可选地图背景 |
| levels[0..2].background.src | 三关各自背景 |
| levels[0..2].outfits[0..1] | 共六套装扮；src 图片、label 名称、text 卡片文案 |
| levels[0..2].outfits[0..1].background.src | 每套装扮绑定的独立背景，共 6 个；换装时立即同步替换 |
| levels[0..2].introTitle / introText | 开场卡文案 |
| levels[0..2].origin | 本关机票出发地，独立于关卡名称 |
| levels[0..2].destination | 本关机票目的地 |
| levels[0..2].ticketTitle / ticketText | 机票标题、说明 |
| levels[0..2].gallery | 图文数组；src 图片、label 标题、text 配文 |
| levels[0..2].galleryUrl | 确认机票后可跳转的外部图文页；留空使用内置页 |

例如把 hero.src 填为 `assets/hero.png`，station.src 填为 `assets/ticket-station.png`。所有图片可替换为你指定的素材，游戏内人物图片等比例缩放、脚底对齐，碰撞范围独立于图片尺寸。像素图片建议透明 PNG、朝右、脚底贴边、少透明边距；柜台图窗口中间需透明，便于看到后方伙伴。背景 cover 居中裁切，图文页图片保持完整比例。

默认美术：红帽蓝背带裤主角、棕色蘑菇怪、红蘑菇、绿水管、橙砖与问号块。三关分别为地上世界、地下水道、黄昏城堡；配置有正式背景图后将覆盖默认像素背景。

## 变装背景与旅程回忆

每关初始背景仍用 `levels[i].background.src`。两次随机换装分别使用所选装扮的 `levels[i].outfits[j].background.src`，与装扮图片绑定，随机顺序不影响对应关系。弹出装扮卡时背景已切换，确认卡片后继续在新背景中游玩；重玩关卡恢复初始背景。换背景不会重置碰撞、水管、金币或平台。

例如：`levels[0].outfits[0].background.src = "assets/world1-outfit1-background.png"`。空 src 使用背景对象 variant 指定的内置像素背景；正式图片设好后 variant 不影响图片。每关有初始背景加两套装扮背景，共三个阶段。

通关图文页标题为“本关名称·旅程回忆”，机票确认按钮为“收好机票，回忆本次旅程”。

当前机票路线：第一关 西双版纳 → 普洱；第二关 普洱 → 昆明；第三关 昆明 → 北京。出发地为当前关卡，目的地为下一站，北京为最终终点。

## 像素音效

`sound.js` 通过本地 Web Audio 合成短音效，无外部音频依赖。包括跳跃、顶砖、金币、蘑菇变装、高级外援和弦、踩怪、受伤、落坑救援、到站、付款、机票和确认按钮音。地图页加载即创建共享 AudioContext 并尝试播放；手机自动播放受限时，在地图页点击“点击开启旅途音乐”即可出声，无需进入关卡。音效开关在地图及游戏内均可使用，每次打开默认开启，本次页面内可以手动静音。页面转入后台暂停音频，下次交互恢复；不支持音频的浏览器继续无声游玩。并发声部限制为 20，振荡器结束后断开连接。

音效验证：`node tests/sound.cjs`。验证首次手势解锁、12 类音效、共享上下文、静音保存及不支持音频时的容错。

## 生命与机票兑换条件

每关开始或重新挑战恢复3条命。碰到怪物受伤扣1条并有1.6秒受伤保护；掉坑扣1条并回到存档点，保留金币。生命归零停止游戏，显示重新挑战/返回地图。普洱高级外援保留碰撞免伤与免费落坑救援。

requiredCoins() 根据路途金币数量与问号砖数量计算，目前24+4=28。HUD显示当前/目标金币和剩余爱心。少于28枚到终点不会开始结算或解锁下一关，玩家可返回补收；每个问号砖仅掉1枚，金币弹出动画结束后才计入。收齐后交付全部金币，再显示机票。

游玩画面的路线说明已移除，仅受伤、救援、金币不足时显示3秒的反馈。地图页文案仍保留地点描述。

地图音乐测试：node tests/map-music.cjs，覆盖自动播放允许/拦截、默认开启、地图按钮恢复、后台暂停与防止多重循环。
