# 透明人物素材处理记录

模式：imagegen 编辑现有图片，输出透明 PNG。五张文件保留原命名，并直接用于游戏。

通用提示词：仅提取原图中的完整人物，移除白色或棋盘格背景以及人物外部文字，输出真实透明 alpha；保留人物脸部、服装、姿势、像素画风和白色衣服，不新增或重新设计人物。莎2-3 中两个人作为完整组合保留。

文件：莎2-1.png、莎2-2.png、莎2-3.png、终点2-1.png、终点2-2.png。

验证：五张均为 RGBA，存在 alpha=0 的透明区域和 alpha=255 的人物区域；已在实际游戏卡片中检查透明效果。


## 西双版纳六张素材

使用内置 imagegen 的 background-extraction 编辑模式。输入为本次上传的六张“(1).png”原件，原件保留不改；游戏引用副本命名为 assets/banna/莎1-1.png、莎1-2.png、莎1-3.png、终点1-1.png、终点1-2.png、终点1-3.png。

每张共用提示词：仅提取完整原人物；输出真实透明 alpha PNG；移除白底、棋盘格与人物外文字；白色衣服保持不透明；保留原脸、发型、服装、姿势、比例、黑色像素轮廓、手脚；不重新设计、不添加物件、不裁掉伸展肢体。

验证：六张均为 RGBA，alpha 包含 0 与 255；完整人物和终点伙伴已在游戏中检查。
